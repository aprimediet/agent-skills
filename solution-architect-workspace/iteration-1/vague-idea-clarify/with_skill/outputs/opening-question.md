# Opening Clarifying Question

"A notification system" can mean very different things depending on scope. To anchor the breakdown, I need one thing first:

**What channels does this notification system need to deliver through — in-app notifications, email, SMS, push (mobile/web), or some combination — and roughly what kind of product is it for (e.g., a web SaaS app, a mobile app, an internal tool)?**

This single answer determines the channel-delivery capabilities, the user-preference model, and the integration surface, so it's the highest-leverage thing to pin down before going further.
